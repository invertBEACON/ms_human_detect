# README

[![DOI](https://zenodo.org/badge/1068850474.svg)](https://doi.org/10.5281/zenodo.21538260)

Data and analysis code for White et al. (2026) Chromatic contrasts predict human target detection in a natural search task.

## Directory structure

- `data/`
  - `data_detections.csv` — detection trial data (one row per target-presentation).
  - `target_specs.csv` — reflectance spectra of the targets and background used in the detection trials.
  - `irrad/` — raw irradiance spectra of downwelling skylight, in per-measurement subfolders (`.JazIrrad` files).
  - `metadata.txt` — data dictionary describing every file and column above.
- `R/`
  - `01_analysis.R` — full analysis script. Performs data cleaning, merging, visual modelling, statistical modelling, and figure generation.
- `figs/` — output figures generated by the analysis code.

## Reproducing the analysis

Run `R/01_analysis.R` from within the `R/` directory (paths are relative, e.g. `../data/`). Requires R (≥ 4.3) with the packages listed at the top of the script: tidyverse, patchwork, lme4, easystats, DHARMa, pavo, MuMIn, and broom.mixed.
