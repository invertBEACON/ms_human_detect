# README

Data and analysis code for White et al. (2025) Seeing through the light: colour contrasts drive human detection in the wild.

## Directory structure
- data/
  - raw/
    - data_detections.csv: detection trial data.
    - target_specs.csv: reflection spectra of targets used in the detection trials.
    - irrad/ raw irradiance spectra of downwelling skylight during each individual trial. 
  - R/
    - 01_analysis.R: full analysis script. Performs data cleaning, merging, modelling, and figure generation.
  - figs/
    - Output figures from the analysis, generated by code.
